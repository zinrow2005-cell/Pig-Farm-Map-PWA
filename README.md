# 豬場查詢系統 V3.3.50 — 單視窗查核／豬場管理流程

## 操作
1. 在地圖按「＋ 標記點」，再點選要判讀的畜牧用地。
2. 同一個「豬場地址共同編輯」視窗內選擇「確認是豬場／疑似豬場／非豬場／稍後查」。
3. 確認或疑似豬場：填寫資料，或搜尋並連結既有豬場，避免建立重複名冊。
4. 管理員直接核定；一般已登入 Google 使用者送交管理員審查。雲端成功寫入才更新正式場址。
5. 非豬場或稍後查：僅保存本機查核，不建立正式豬場；可於人工查核歷史取消。

## 重要
* 保留原有人工查核進階模式與跨裝置查核分頁。
* 未登入者可瀏覽及保存本機非豬場查核，正式豬場送審須登入。
* 不會重新初始化 315 筆名冊，不會自動刪除正式資料。
* Firestore 安全規則沿用 V3.3.46，這次不新增集合或權限。
* 正式 Firestore 交易、真實 GPS／地圖圖磚及手機觸控尚須在正式網站驗收。
