# 豬場地圖查核 V3.3.41 — 詳細資料視窗刪除入口

以 V3.3.39 完整部署包為基礎。

- `manual-...` 且不是正式雲端資料：豬場詳細資訊直接顯示「✕ 刪除本機豬場」。不需 Google 登入。刪除後須成功保存 IndexedDB 或 localStorage 才確認完成；失敗會恢復。
- Firestore 雲端正式豬場：已登入且管理員權限完成驗證時直接顯示「✕ 刪除正式豬場」，須二次確認並完整輸入名稱；僅在雲端交易成功後變更地圖、清單、統計。
- 一般使用者無權刪除雲端正式豬場；初始名冊及官方 F03 圖資不會因本機操作被刪除。
- 舊有「查核歷史 → 刪除本機標記」功能保持原狀；本機豬場與查核地塊紀錄是兩種不同物件。
- 沿用 V3.3.39 Firestore 安全規則，這一版不須額外更改。

部署前先備份，整包取代網站檔案。請在實際站台測試 Firestore 管理員刪除，因離線測試無法證明正式雲端權限。

V3.3.41：從地圖標記的 ⓘ 打開詳情，標題右側直接顯示「刪除本機豬場」或「刪除正式豬場」；刪除時再次驗證權限，無需回左側清單。
