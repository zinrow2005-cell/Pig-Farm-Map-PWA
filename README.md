# 豬場查核 V3.3.39｜本機標記刪除

一般訪客、已登入使用者與管理員，都可以刪除**這台裝置**的人工查核標記，不需要 Google 登入。

## 操作
1. 點「盤查工作台 → 人工查核紀錄」，在每筆記錄右側直接點「刪除本機標記」；手機與電腦均可。
2. 或點地圖上的自建查核標記或已著色地塊，在「畜牧地塊查核」面板頂部點「刪除本機標記」。
3. 確認後，系統會刪除本機查核紀錄，重新繪製查核圖層和統計；如果該記錄產生了未核定的獨立本機豬場點，且沒有被其他記錄關聯，亦會移除該點。
4. 已正式核定的雲端豬場**不會**被移除；一般使用者已經送出的雲端申請也不會因本機刪除而撤回。管理員正式刪除仍使用「共同編輯」功能。

## 重要
刪除只影響目前瀏覽器的本機儲存；裝置清除網站資料或匯入舊備份，可能恢復舊標記。建議先備份 JSON。
這版不需要變更 Firestore 規則。
