# 豬場地圖查核 V3.3.24｜公開使用操作說明版

## 本版新增

在 **V3.3.21** 基礎上增加直接內嵌的系統使用說明：

- 桌機頂部：**❔ 使用說明**；「⋯ 更多」也提供備用入口。
- 手機／平板底部導覽列：**❔ 使用說明**，無需打開豬場清單或登入。
- 四個頁籤：**快速上手、地圖判讀、提交更正、管理員／常見問題**。
- 可以直接按「開始搜尋豬場」、「開啟豬場清單」或「Google 登入」銜接現有操作。
- 支援關閉、背景點擊、Esc、鍵盤導覽；小螢幕可捲動，底部返回地圖按鈕不被 PWA 工具列遮住。
- 明確說明：**未登入可查閱；登入才可提交雲端更正；管理員核准才修改正式場址**。

本版**不修改**既有315筆豬場、112年3593個多邊形、Firebase 設定／安全規則／登入及審核程式。

## GitHub Pages 上傳

1. 先備份目前尚未同步的人工查核資料。
2. 解壓 ZIP，**整包所有檔案與子資料夾**放入 GitHub Pages 儲存庫的網站根目錄，覆蓋 V3.3.21。
3. 不要只替換 `index.html`；本版新增 `assets/css/help-v3322.css`、`assets/js/help-v3322.js`。
4. 已更新 `sw.js` PWA 快取版本。檢查網址畫面顯示 **V3.3.24**。
5. 點「使用說明」測試四個頁籤，關閉後檢查地圖不被占位；手機底部也應能隨時開啟。

## 重要限制

- GitHub Pages 真實 Leaflet／PHOTO2、Google 登入及 Firestore 即時權限仍須在網站上實機驗收。
- 系統公開使用前，管理員仍需完成 Firestore 315 筆正式場址初始化、安全規則及雙帳號寫入測試。
- 本版只是介面導覽，並**未將本機人工查核變成雲端同步**。
