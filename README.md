# 豬場查詢系統 V3.3.60 — Canvas 名稱顯示效能版

## 更新重點
- 手機、平板名稱採單一 Canvas 繪製，不再對每個名稱建立 Leaflet DOM Marker。
- 手機在雙地圖時只於右側航照顯示名稱，單圖則於當前顯示圖繪製。
- 放大至 Z15 才顯示，畫面內最多 12 個名稱；電腦 Z15 起，最多 50 個。
- 放大縮小、拖曳期間暫停名稱，停止約 360ms 後再繪製。
- 使用地理網格索引限制查詢區域，Canvas 完全不接收指標事件。
- 修正舊版 iOS Safari Canvas 不支援 roundRect 的相容性問題。

## 部署
完整覆蓋 GitHub Pages 網站檔案。Firestore 規則沿用 V3.3.46，原有豬場資料不須重新初始化。

## 注意
目前提供的是效能優化，不保證所有手機在其他圖層與圖磚負載下均無卡頓。若仍卡頓，下一步須量測 F03 向量層與航照圖磚的耗時。


## V3.3.60 小幅調整
手機／平板豬場名稱從縮放 Z15 開始顯示（原 Z16），與電腦相同門檻，仍使用輕量 Canvas 並限制同時最多 12 個名稱。

## V3.3.60 顯示距離修正
- 手機與平板名稱從 Z15 開始顯示，和電腦版一致；不需放大至 Z16。
- 仍維持每張可見地圖最多 12 個名稱，Canvas 不攔截點擊，避免手機卡頓。
- 在手機雙圖模式，名稱顯示於右側航照；單圖模式顯示於目前使用的圖。
- 若更新後看起來沒變，請確認左上角版號 V3.3.60，並重新載入 PWA 以切換離線快取。
