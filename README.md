# 豬場地圖查核 V3.3.48 — 共同編輯操作介面修正版

## 本次修改
- 共同編輯拆為三個工作分頁：① 豬場管理／② 待審核定／③ 跨裝置查核。
- 將登入、儲存、權限或 Firebase 問題的提示移到視窗內，不再只顯示在被遮住的頁面頂端。
- 「查看待審」現在切換至待審分頁，不再只是捲到下方。
- 既有豬場搜尋、選取及地圖選點流程保留；未登入或權限尚未確認時，明確顯示下一步。
- 把初始化 315 筆名冊移到「進階管理」摺疊區，避免日常操作誤點。
- 縮小手機按鈕佔用的高度，修正隱藏按鈕被 CSS 顯示的風險。

## 常見操作
1. 新增：地圖上「＋ 標記點」→ 選地塊 → 填寫名稱、地址 → 管理員直接核定／一般使用者送審。
2. 修改既有：共同編輯 → 豬場管理 → 搜尋既有豬場 → 選取原資料編輯，沿用原 ID。
3. 核准：共同編輯 → 待審核定；管理員核准一般使用者的案件。
4. 雲端查核：共同編輯 → 跨裝置查核；讀取、上傳或匯入缺少的紀錄。

## 部署
本版本直接覆蓋 GitHub Pages 的網站檔案即可；Firestore 規則沿用 V3.3.46 的規則，前提是已經發布。請先匯出備份，勿重新初始化 315 筆名冊。

已執行 JavaScript 語法、HTML 結構及 Chromium 隔離表單／分頁操作測試。正式 Firebase 登入、讀寫與完整 Leaflet 圖層的實機操作尚未完成線上驗收。
