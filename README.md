# 豬場地圖查核 V3.3.56｜管理員直接核定修正版

基於 V3.3.55 整理完整版，保留全部網站程式、豬場資料及既有 Firebase 結構。

## 已修改
- 「豬場地址共同編輯」→ 編輯既有豬場：新增「✓ 管理員直接核定此豬場」獨立按鈕。
- 核定時要求有效經緯度，並二次確認；名稱、縣市、鄉鎮也不可空白。
- 核定寫回原 `farms/{uid}`，同一交易寫入地址、座標、 `auditDecision: pig` 與既有 F03 關聯，並讓原 UID 不變。
- 單純「儲存資料修改」不會默默宣告核定成功。
- 雲端失敗時顯示錯誤，不會將本機當作成功。
- 在視窗顯示目前雲端定位／核定狀態。
- 已核定是「管理員人工確認豬場」，不代表政府核發的官方地址／登記證明。
